## ✨ Interactive Architecture & UX Highlights

- **On-Load & Route Transition Animations:** Smooth preloader animation with floating bi-color capsule and sleek top progress bar (`#page-loader-bar`).
- **Scroll Reveal Animations:** IntersectionObserver-powered `.reveal-on-scroll` effects with staggered delays across cards and sections.
- **Instant Product Search:** Live search filtering by brand name, generic molecule composition, and therapeutic category.
- **Clinical Monograph Views:** Complete dosage protocols, composition breakdown, indications, pharmacokinetics, and storage instructions.
- **Open Healthcare Professional Portal:** Un-gated clinical reference dossiers, downloadable clinical monographs, and direct Physician Academic Sample Requisition form.
- **Distributor Partnership Gateway:** Commercial supply inquiry channel with Drug License verification.
- **Search Engine Optimization (SEO):** Rich meta tags, high-converting pharma keywords, Open Graph, Twitter Cards, and Schema.org JSON-LD structured data.

## 🚀 Local Development Setup

To run the local server:

```bash
# Clone the repository
git clone https://github.com/rpalanirajan18-cloud/Bynex-Pharma.git
cd Bynex-Pharma

# Start the web server
node server.js
```

Open your browser at **`http://localhost:3050`**.
